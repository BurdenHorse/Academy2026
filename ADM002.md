## 3. Xử lý chi tiết màn hình

### 3.1 Hiển thị ban đầu

Khởi tạo điều kiện search mặc định:

- `fullname` = rỗng
- `department` = rỗng
- `page` hiện tại = **1**
- Sort mặc định: `氏名`, `日本語能力`, `失効日` đều = **ASC** (icon ▲▽)
- Số record tối đa / trang = **20** (luôn cố định)

Gọi **API List departments**:

- Lỗi → hiển thị message `部門を取得できません`
- Thành công → bind list vào dropdown (có phần tử rỗng ở đầu)

Gọi **API List employees**:

- Lỗi → hiển thị message `従業員を取得できません`
- Thành công → bind list vào bảng nhân viên

### 3.2 Binding data vào list

- Clear data cũ trong bảng (nếu có), binding theo đúng thứ tự response trả về
- Mapping từng hạng mục theo bảng **2.2**
- Nếu list rỗng → **ẩn** control paging và hiển thị message `検索条件に該当するユーザが見つかりません。` (**MSG005**) ngay trên bảng
- Nếu tổng số record (không tính phân trang) **≤ 20** → **không** hiển thị control paging

### 3.3 Action Search

- Reset `page` = 1
- **Giữ nguyên** điều kiện sort hiện tại
- Lấy `fullname` (textbox) + `department` (dropdown) + `page` + `sort` → tham số gọi API List employees
- Nếu `fullname` rỗng hoặc `department` rỗng → KHÔNG đưa tham số đó vào request
- Cách gọi & binding: theo 3.1 và 3.2

### 3.4 Action Sort

- Click vào cột có icon sort → **đảo ngược** trạng thái sort của cột đó, các cột khác giữ nguyên
    - ASC (▲▽) → click → DESC (▼△) → gọi API
    - DESC (▼△) → click → ASC (▲▽) → gọi API
- **Giữ nguyên** điều kiện search
- Reset `page` = 1
- Gọi API List employees với tham số tương ứng

### 3.5 Action Paging

- Click page nào → gọi lại API, **giữ nguyên** điều kiện search + sort, chỉ đổi `page`
- Cách gọi & binding: theo 3.1 và 3.2

### 3.6 Action Add

- Click button Add → chuyển sang màn hình Add/Edit **ADM004**

### 3.7 Action View chi tiết

- Click link ở cột **ID** → gọi API Get Employee, redirect sang **ADM003** kèm ID tương ứng
- Truyền ID qua **URL query param** `id` — ví dụ `/employees/adm003?id={employeeId}` (kèm query string tìm kiếm/sort hiện tại để hỗ trợ quay lại ADM002)

### 3.8 Danh sách message

| Mã | Nội dung | Khi nào |
| --- | --- | --- |
| MSG005 | `検索条件に該当するユーザが見つかりません。` | List employees rỗng |
| — | `部門を取得できません` | API departments lỗi |
| — | `従業員を取得できません` | API employees lỗi |

| json key | Kiểu | Ghi chú |
| --- | --- | --- |
| code | number | 200 |
| departments | array | Mảng thông tin phòng ban |
| departments[].departmentId | number |  |

```json
{
  "code": 200,
  "departments": [
    { "departmentId": 1, "departmentName": "Phòng DEV1" },
    { "departmentId": 2, "departmentName": "Phòng DEV2" }
  ]
}
```

**Response — lỗi**

```json
{
  "code": 500,
  "message": { "code": "ER023", "params": [] }
```

**Xử lý phía server**

1. Get tất cả phòng ban từ bảng `departments` (các trường: `department_id`, `department_name`).
2. Không lỗi → trả `code = 200` + list departments.
3. Có lỗi → trả `code = 500`, `message = { code: "ER023", params: [] }`.

## 5. Code API tham khảo (Spring Boot – Java)

> Stack tham khảo: Spring Boot + MyBatis/JPA. Coding agent có thể adapt sang stack khác nhưng phải giữ đúng **contract** (endpoint, param, response shape, error code) ở mục 4.
> 

### 5.1 Response wrapper & DTO

### 5.2 Controller

```java
@RestController
@RequestMapping
public class MasterController {

    private final DepartmentService departmentService;
    private final EmployeeService employeeService;

    public MasterController(DepartmentService d, EmployeeService e) {
        this.departmentService = d;
        this.employeeService = e;
    }

    // API 4.1 - Get List Departments
    @GetMapping("/departments")
    public ResponseEntity<?> getDepartments() {
        try {
            List<DepartmentDto> list = departmentService.getAll();
            Map<String, Object> body = new HashMap<>();
            body.put("code", 200);
            body.put("departments", list);
            return ResponseEntity.ok(body);
        } catch (Exception ex) {
            return ResponseEntity.status(500).body(error("ER023"));
        }
    }

    // API 4.2 - Get List Employees
    @GetMapping("/employees")
    public ResponseEntity<?> getEmployees(
            @RequestParam(required = false) String fullname,
            @RequestParam(required = false) Long departmentId,
            @RequestParam(defaultValue = "1") int page,
            @RequestParam(defaultValue = "name") String sortField,
            @RequestParam(defaultValue = "ASC") String sortType) {
        try {
            EmployeeSearchResult result = employeeService.search(
                fullname, departmentId, page, 20, sortField, sortType);
            Map<String, Object> body = new HashMap<>();
            body.put("code", 200);
            body.put("totalRecords", result.getTotal());
            body.put("page", page);
            body.put("size", 20);
            body.put("employees", result.getItems());
            return ResponseEntity.ok(body);
        } catch (Exception ex) {
            return ResponseEntity.status(500).body(error("ER024"));
        }
    }

    private Map<String, Object> error(String code) {
        Map<String, Object> msg = new HashMap<>();
        msg.put("code", code);
        msg.put("params", new ArrayList<>());
        Map<String, Object> body = new HashMap<>();
        body.put("code", 500);
        body.put("message", msg);
        return body;
    }
}
```

### 5.3 Service — Employees (search + sort + paging)

```java
@Service
public class EmployeeService {

    private final EmployeeMapper mapper; // MyBatis

    public EmployeeService(EmployeeMapper mapper) { this.mapper = mapper; }

    // Whitelist chống SQL injection cho ORDER BY
    private static final Map<String, String> SORT_COLUMN = Map.of(
        "name", "e.full_name",
        "jlpt", "e.jlpt_level",
        "expiryDate", "e.cert_expiry_date"
    );

    public EmployeeSearchResult search(String fullname, Long departmentId,
            int page, int size, String sortField, String sortType) {
        String orderCol = SORT_COLUMN.getOrDefault(sortField, "e.full_name");
        String orderDir = "DESC".equalsIgnoreCase(sortType) ? "DESC" : "ASC";
        int offset = (Math.max(page, 1) - 1) * size;

        // fullname/departmentId null → không đưa vào điều kiện WHERE
        int total = mapper.countEmployees(fullname, departmentId);
        List<EmployeeDto> items = mapper.findEmployees(
            fullname, departmentId, orderCol, orderDir, offset, size);

        return new EmployeeSearchResult(total, items);
    }
}
```

### 5.4 SQL (MyBatis) — Employees

```xml
<select id="findEmployees" resultType="EmployeeDto">
  SELECT
    e.employee_id            AS employeeId,
    e.full_name              AS fullName,
    DATE_FORMAT(e.date_of_birth, '%Y/%m/%d')     AS dateOfBirth,
    d.department_name        AS departmentName,
    e.email                  AS email,
    e.phone_number           AS phoneNumber,
    e.jlpt_level             AS jlptLevel,
    DATE_FORMAT(e.cert_expiry_date, '%Y/%m/%d')  AS certExpiryDate,
    e.score                  AS score
  FROM employees e
  LEFT JOIN departments d ON d.department_id = e.department_id
  <where>
    <if test="fullname != null and fullname != ''">
      AND e.full_name LIKE CONCAT('%', #{fullname}, '%')
    </if>
    <if test="departmentId != null">
      AND e.department_id = #{departmentId}
    </if>
  </where>
  ORDER BY ${orderCol} ${orderDir}
  LIMIT #{size} OFFSET #{offset}
</select>

<select id="countEmployees" resultType="int">
  SELECT COUNT(1)
  FROM employees e
  <where>
    <if test="fullname != null and fullname != ''">
      AND e.full_name LIKE CONCAT('%', #{fullname}, '%')
    </if>
    <if test="departmentId != null">
      AND e.department_id = #{departmentId}
    </if>
  </where>
</select>
```

<aside>
⚠️

`${orderCol}` / `${orderDir}` là string substitution → **bắt buộc** dùng whitelist (`SORT_COLUMN` + kiểm tra ASC/DESC) để tránh SQL injection. Không bao giờ truyền thẳng giá trị từ request vào `ORDER BY`.

</aside>

### 5.5 SQL — Departments

## 8. Danh sách message đầy đủ (từ Message.xlsx)

<aside>
⚠️

**Đính chính so với mục 4 & 6:** File message master chỉ định nghĩa mã lỗi đến **ER023**, và `ER023` là **lỗi hệ thống chung** (`システムエラーが発生しました。` / Hệ thống đang có lỗi). Vì vậy **không có mã ER024**. Khi API lấy departments/employees lỗi, ở tầng API dùng `ER023`; còn các text `部門を取得できません` / `従業員を取得できません` là **message cố định hiển thị trên màn hình** (không nằm trong master).

</aside>

### 8.1 Message thông báo (MSG)
